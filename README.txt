FORTI52 TECHNOLOGIES - GITHUB PAGES

1. Unzip this package.
2. Create a PUBLIC GitHub repository named forti52-website.
3. Upload index.html, about.html and the assets folder to the repository ROOT (not inside another folder).
4. Go to repository Settings > Pages > Build and deployment. Choose Deploy from a branch, main, /(root), then Save.
5. Visit https://YOUR-USERNAME.github.io/forti52-website/

CUSTOM DOMAIN: In Settings > Pages enter forti52.com. At GoDaddy DNS set apex A records to GitHub Pages IP addresses as documented at https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site . Set www CNAME to YOUR-USERNAME.github.io if using www. Preserve existing MX/TXT records for email. Enable Enforce HTTPS once available.
